Thêm ứng dụng

App có file ảnh, CSS hoặc JavaScript đi kèm?

Bản này nhận một file HTML. Nếu app dùng tài nguyên tương đối, nhập thư mục HTTPS chứa tài nguyên, kết thúc bằng dấu /.

Xuất bản để thêm hoặc cập nhật app. Allinone không tự lưu hay khôi phục biểu mẫu. App cần file phụ hoặc máy chủ thì các kết nối đó vẫn phải sẵn sàng.

Xem trước app

Xem trước dùng cùng chế độ chạy với app đã xuất bản. Dữ liệu và API của app vẫn là dữ liệu thật.

Trợ giúp

01

Mở mới mỗi lần chọn tab

App trước được đóng khi chuyển tab hoặc về Tổng quan. Allinone không tự lưu và không khôi phục nội dung nhập dở. App con có thể tự lưu dữ liệu theo chức năng riêng của nó.

02

Thêm hoặc cập nhật app

Quản trị → Thêm ứng dụng HTML → Chọn file → Xuất bản. Khi thay app hiện có, dùng Cập nhật HTML tại đúng app đó. Không cần sửa mã Allinone cho mỗi lần thêm app.

03

Lấy phiên bản mới

Mỗi lần chọn tab, Allinone kiểm tra danh sách và lấy lại HTML. Danh sách cũng tự kiểm tra mỗi 60 giây khi trang đang hiển thị. App đã cập nhật trên kho sẽ được mở lại; sáu app mặc định tiếp tục lấy mã từ GitHub. Khi không có mạng, chưa thể xác nhận bản mới nhất.

04

App có máy chủ hoặc file phụ

File HTML cần chứa đủ mã hoặc trỏ đúng đến các tài nguyên đang trực tuyến. Máy chủ, đăng nhập và quyền thiết bị vẫn phải được cấu hình phù hợp. Hãy kiểm tra chức năng chính của app trong Allinone trước khi dùng chung.
